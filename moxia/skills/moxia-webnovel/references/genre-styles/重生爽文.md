# 题材风格包：重生爽文

> 一句话定位：**主角带着前世记忆/经验重生，用信息差碾压对手，实现逆袭打脸。** 读者要的是「早知今日」的掌控感 +「碾压前世仇人」的爽感。

---

## 叙述腔调

第一人称「我」，重生者视角。前期冷静布局，中期步步为营，后期当众打脸。

腔调从"看透一切的从容"到"碾压对手的痛快"。与悬疑的冷静不同，重生爽文的冷静是**成竹在胸**，不是恐惧压抑。

重生者可以适度剧透未来（"他们不知道，三天后这家公司会破产"），用信息差制造期待。

## 开篇范式

| 开篇式 | 示例 |
|--------|------|
| 死亡瞬间+睁眼重生 | 我死在那场精心策划的车祸里。再睁眼，回到了十年前的大学宿舍。 |
| 前世结局+重生节点 | 上一世，我被最好的闺蜜抢走一切，惨死在出租屋。这一世，她还想故技重施？ |
| 信息差展示 | 看着眼前这个还没发迹的穷小子，我笑了。三年后，他会成为身价千亿的大佬。 |
| 立 flag | 重生回来第一天，我做的第一件事，就是把前世害死我的人拉黑。 |

## 钩子母题

- **信息差碾压**：主角提前知道对手的阴谋、未来的机遇、市场的走向
- **扮猪吃虎**：主角表面普通，实则深不可测，关键时刻亮底牌
- **当众打脸**：前世欺负主角的人被反杀，而且被碾压得很惨
- **资源抢占**：主角提前布局，抢占未来的机遇（买房、买股、投资）
- **前世仇人清算**：一一回收前世的仇恨，账一笔笔算
- **逆天改命**：改变前世悲剧的结局，保护前世没保护好的人

## 情绪烈度（烈度 8-9）

爽感直接、强烈。打脸要干脆利落，不拖泥带水。

- 碾压时用冷静的陈述，越平静越爽："你刚才说什么？再说一遍。"
- 打脸后给对手留白，不解释太多，让读者自己品
- 偶尔用前世记忆制造"细思极恐"的对比：前世我跪在这里求他，这一世，轮到他跪我

## 对话风格

**① 主角的从容打脸**
- "你确定要跟我赌？"（三章后对方输得倾家荡产）
- "你觉得我什么都不懂？那你就等着看吧。"

**② 对手的嚣张（打脸前）**
- "就凭你？也配跟我争？"
- "穷鬼，别痴心妄想了。"

**③ 对手的崩溃（打脸后）**
- "不可能！你怎么可能知道……"
- "你到底是谁？！"

**④ 旁观者的震惊**
- "他……他真的做到了？"

## 节奏骨架

```
导语（前世惨死 + 重生睁眼）
→ 第1章：确认重生时间节点，立下改命目标
→ 布局阶段：主角利用信息差提前行动（抢占资源、疏远仇人）
→ 第一次打脸：小试牛刀，碾压前世看不起自己的人
→ 中期升级：对手开始反扑，主角借力打力
→ 终极清算：当众揭穿对手的阴谋，彻底碾压
→ 收尾：前世仇人下场凄惨，主角走向人生巅峰
```

## 收尾

- 前世仇人得到报应（破产、入狱、身败名裂）
- 主角实现前世未完成的梦想
- 保护好前世没保护好的人
- 开放式暗示新的人生（与网文不同，爽文可以开放式收尾）
