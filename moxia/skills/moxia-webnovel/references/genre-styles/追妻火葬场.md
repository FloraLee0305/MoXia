# 题材风格包：追妻火葬场 / 虐恋意难平

> 一句话定位：**最亲密的人（丈夫/未婚夫/父母）为「白月光」牺牲主角，将主角一步步折磨到心死；主角冷静决裂离场，施害者后悔莫及，进入追悔火葬场。** 读者要的是「被珍视感的彻底剥夺」+「心死后的扬眉吐气」。

---

## 叙述腔调

以受害者第一人称「我」全程主导，贴着体感和心跳写：疼就说疼，心死就说心死。前半段用口语化的内心独白和反问宣泄委屈，撞破真相后切成冷静、反讽、居高临下的审判腔。

**允许并鼓励向前剧透「火葬场」结局来吊人。**

开口就是带占有关系的称呼："我老公/我丈夫/我未婚夫"。

## 开篇范式

正文最前面先放一段**结果倒序的导语**，把背叛全貌 + 心死 + 「可后来他后悔了」一次性剧透。

| 开篇式 | 示例 |
|--------|------|
| 关系+年限锚点 | 和裴筠舟成亲的第七年，他带回了一个罪奴，是他的白月光。 |
| 第一句即背叛炸弹 | 第一次发现丈夫和别人滚在床上，是在我们的婚房里。 |
| 灾难求救被辱 | 老公怕我打搅他跟小秘书看演唱会，将我锁在家里。突发火灾，我打电话给他求救，只换来他一句："能不能大度点？" |
| 反差身份钩 | 我给傅深当了八年替身。 |

## 钩子母题

密度极高，**阶梯式背叛：道德 → 经济 → 生命。**

- **白月光触发链**（核心母题）：男人有个白月光/小青梅/前妻，关键时刻为她牺牲妻子
- **偷听/撞破真相一次性砸**：无意听见渣男和白月光的真心话，全盘真相一次性砸下
- **灾难期求救反被辱**：火灾/地震/早产时向丈夫求救，换来冷漠或咒骂
- **朋友圈配文当刀**：渣男/白月光发的甜蜜配文被主角刷到
- **数字/年限承重再清零**：结婚七年、陪你十年，堆出投入再被一句话清零
- **火葬场前瞻预告**：导语结尾透露追悔 payoff（"我还不知道，他正发疯似的在国内找我"）

## 情绪烈度（烈度 9）

前半直白宣泄 + 撞破真相后冷静审判（钝刀转冷刀）。

- 直接命名情绪并加重：心如死灰、心彻底凉透、伤心欲绝、泪如雨下
- 内脏/心脏拟痛："巨大的悲痛在一点点啃食我的心脏"
- 心死后转冷反衬："这些话出自最亲密的人之口，却已经激不起我任何波澜"

## 对话风格

**① 施害者道德踩踏狠话（钩子本体）**
- "能不能大度点，不就是拿你两张演唱会门票吗？"
- "婉婉身子弱，受不了这种惊吓。"

**② 白月光娇弱软刀**
- "对不起，笙笙姐姐，都怪我非要让池哥哥陪我去看演唱会。"

**③ 主角心死后冷静审判金句**
- "结婚七年，你连我穿多大码的鞋都不知道，再在一起，就再没必要了。"
- "秦总误会了，我纯粹觉得你比较可笑。"

## 节奏骨架

```
导语（结果倒序 + 火葬场预告）
→ 逐节背叛升级（道德→经济→生命）
→ 偷听/撞破真相
→ 心死定格
→ 冷静审判 + 净身出户/反击
→ 渣男追悔/发疯（火葬场）
```

## 收尾

- 火葬场反转：主角走后渣男后悔莫及/发疯/求原谅，主角已无波澜或冷拒
- 转身求婚/改嫁他人，当众完成关系翻转
- 带孩子/带资产一去不归，开启新人生
- 反讽对位：用渣男视角写他失去后的崩溃，漠视比报复更狠
