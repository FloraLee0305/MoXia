# 题材风格包：甜宠恋爱线

> 一句话定位：**纯甜双向奔赴 / 先虐后甜 / 暗恋成真 / 先婚后爱 / 救赎，以 HE 收尾。** 读者要的是「被偏爱的例外感」+「嘴硬心软的拉扯」。

---

## 叙述腔调

第一人称「我」（多为女主）主导，轻快、自嘲、口语。主引擎是**内心吐槽小剧场**：表面言行与心理活动的反差制造喜感。

男主可以是冰块脸/毒舌/病弱伪装，关键处用短台词撩拨或露出反差。

先虐后甜的前段用压抑克制腔，转甜后切回轻快，让甜成为熬过压抑的奖赏。

## 开篇范式

导语抛出「关系错位 + 一句杀伤力台词」，让读者立刻看懂误会。

| 开篇式 | 示例 |
|--------|------|
| 误发消息/打错电话 | 电话那头传来低沉又戏谑的声音："周稚欢，你看清楚，我是谁？" |
| 荒诞事件牵线 | 哥哥不愿去见相亲对象，被爸爸打断了腿。而那个躺在病床上的人，正是我的相亲对象…… |
| 修罗场+对照组 | 情人节渣未婚夫抱走下药的前女友，"我"跌进从不近女色的小叔叔怀里 |
| 强设定自白 | 我是大周赫赫有名的混混公主。 |
| 闯祸定终身 | 醉酒后，不小心睡了一个病秧子。他堵在我家门口，要我负责 |

## 钩子母题

甜宠的钩是**悬着的糖**：让心动、试探、选择和关系后果持续前推。

- **马甲/身份错位**（头号母题）：双马甲互撩、隐藏大佬、网恋对象是身边人
- **例外感投喂**：冰块男主只对女主破例。热橙汁、剔好刺的鱼、一支簪子。物件越小，例外越大
- **强制同框装置**：赐婚/联姻/提亲堵门/病房陪护，把两人锁死在一个空间
- **吃醋触发器**：情敌是工具不是威胁，功能是逼出占有欲和委屈
- **危机见真心**：挡箭、发烧、受伤。嘴硬由行动戳破

## 情绪烈度（烈度 6）

日常轻快，心动瞬间拉高再速降。

- 心跳系：我心跳轻轻乱了一拍
- 温度系：耳朵瞬间烫得要命
- 被抓包系：那你耳朵红什么？

## 对话风格

**① 男主反差撩/占有宣言（低频高杀伤）**
- "放心，我对你没兴趣。""不过那小子，确实配不上你。"

**② 女主嘴贫/口不择言（高频铺糖）**
- "我可以在你腹肌上面弹奏肖邦的夜曲吗？"

**③ 委屈小狗/吃醋台词**
- "为什么把我拉黑？"

**④ 心动确认句（一句定格，独立成段）**
- "不丑，而且这个最好吃。"

## 节奏骨架

```
导语（高概念误会 + 杀伤力台词）
→ 强制同框装置上线
→ 日常糖点与关系选择交替推进
→ 吃醋/情敌小高潮
→ 误会爆发/危机（虐段，短）
→ 真相揭开 + 告白（糖峰值）
→ 确认关系 + 补糖收尾
```

## 收尾

- 告白 + 马甲/误会全部揭开，当面兑现
- 婚礼/领证/回归日常斗嘴定格
- **HE 是硬约束**：不开放式、不 BE
