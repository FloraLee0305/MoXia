# 题材风格包：悬疑 / 惊悚 / 细思极恐

> 一句话定位：**现代悬疑/侦探推理/惊悚/细思极恐。信息差驱动，层层揭底，结尾反转必须能回溯；细思极恐型收尾把最后一块拼图留给读者。**

---

## 叙述腔调

第一人称**冷静报告体**为主：叙述者用记流水账的平静口吻，陈述极不正常的事，恐怖靠「语气与内容的反差」压出来。

叙述者**可以隐瞒，不可以说谎**：第一人称凶手叙述者如实记录自己做了什么，把动机留到揭底时再交代。

与追妻/复仇的宣泄腔相反：全程克制，不哭诉、不控诉、不连环反问。

## 开篇范式

导语用「正常世界 + 一个不可能细节」迅速立住悬念。

| 开篇式 | 示例 |
|--------|------|
| 冷静自白+不可能细节 | 杀死丈夫后，我将他分尸，放进了地下室的冰柜里。第二天，冰柜里出现了两双手，三双脚。 |
| 民俗规矩卡+轮到我 | 村子有个古怪的习俗。年轻貌美的处女，被洞神选中后，就会不吃不喝，直至死亡。直到我的阿姐，被选为「落花洞女」。 |
| 亲人一夜变异 | 我们被笑得浑身发寒。因为她太乖了。乖得不像是六岁的小姑娘！ |
| 存在被抹除 | 王阿姨拉开一条缝，表情像见了鬼："小姑娘，你一个人住那儿三年了，哪来的爸妈？" |
| 死亡通知反转句 | "你老公呢？""死的就是他。" |

## 钩子母题

- **不可能细节**：一个具体、可验证、无法解释的小事实，比大场面吓人
- **全员口径一致的否定**：亲人、邻居、警察统一说你疯了
- **规矩三条，必破一条**：先立规矩，读者从立规矩那刻就在等哪条会破
- **微物证**：反转回溯的锚点。出现时轻描淡写，摊牌时逐一收回
- **知情者微反应**：撒谎者被戳到时的小动作当路标
- **自我留言接力**：循环/失忆型给下一轮的自己留证据

## 情绪烈度（烈度 6）

恐惧短促直写，情绪成语全篇最多一两处；主角越冷静越可怕。

- 恐惧多为一句直写（我不敢动/我怕了）
- 体感（头皮发麻/汗毛竖立）全篇两三处，短促一拍
- 恐惧与理智交替：一拍之后立刻回到分析态
- 崩溃全篇只许一次，放在「全世界都否定我」的至暗点

## 对话风格

**① 否定式对话（世界合谋否认）**
- "谁？你不是一直单身吗？"

**② 试探与验证对话**
- "这个积木还是你5岁生日那天，我送给你的礼物呢。""才不是，这个积木是爸爸给我买的呢。"

**③ 揭底摊牌对话（只收旧账）**
- "你说穿白色连衣裙的是你，可是照片中那个人是右手拿花的。而你是个左撇子。"

**④ 凶手/怪物的平静狠话**
- "爸爸妈妈对花生过敏，只要他们永远睡过去，就没有人让我当神童了。"

## 节奏骨架

```
导语（正常世界 + 一个不可能细节）
→ 异常落地，给出第一个「合理解释」
→ 合理解释被新异常打破（至少两轮）
→ 至暗点（全世界否定我）
→ 假底：能自圆其说的结论
→ 微物证触发真反转
→ 摊牌回溯：前文伏笔逐一收回
```

**回溯是硬约束**：反转依赖的每个证据，摊牌前必须在正文露过面。

## 收尾

- **回溯型摊牌**：揭底后逐条对应前文微物证
- **细思极恐留白**：用一个动作或一句话把最后一块拼图留给读者
- **循环闭合**：结尾回到开头画面，多一个记号，暗示又一轮开始
